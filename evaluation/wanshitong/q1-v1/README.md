## 控制层受控对照

`evaluation/wanshitong/q1_control_compare.py` 从专用 8289 候选的现有
`PrivateReplayDraftRecorder` 读取一次真实发送包。人工先在仓库外选择
充分阅读单元及复核正反变体，程序核对它们均属于同一次 `TRANSPORT_SENT`
发送包，再以同一内网模型运行：A 为充分原文精简读答，B 为同原文的
现有问答层回放，C 为实际发送原文精简读答，D 为同一次公开完整路径结果。
复核变体逐条单独调用真实复核器，统计错放与误拒。B 重建了证据包，
但无法恢复上游 `EvidenceGroup` 与 `ResolvedQueryView` 全部现场状态，
其差异在输出中明确标记，不能冒称产品完整路径；D 才是完整产品结果。
v3 私有记录保留实际阅读单元、物理表格事实和线协议草稿；旧 v2 记录
仅在无表格事实且逐单元摘要与发送包完全一致时允许重建用于对照。
精简路径的无效引用只记录为未发布模型文本，调用错误单独列出。

所有选材、原文、公开回答和模型输出留在仓库外 0700 目录，脚本仅创建
0600 文件。`--validate-only` 只核身份，不调用模型。人工核对原文与答案后，
使用 `evaluation/wanshitong/q1_score_comparison.py` 逐格计算完整答对、
已发布准确、误拒与限定错误；没有人工判分时只记录
`AWAITING_HUMAN_GRADES`。限答与安全拒答不会被算成完整答对。固定十题仍是
回归集合；独立泛化结论必须来自按来源和事实族隔离的新盲测。
