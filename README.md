# 湾小度 V2

湾小度基于腾讯开源 WeKnora，提供院内知识问答、研发管理系统单点登录、三种固定角色和个人资料上传。

开发分支为 `codex/wxd-v2-weknora-090`，稳定发布分支为 `wanshitong-stable`。2026-11-01 已将8289验收版本发布到[生产入口](https://devmng.nat200.top/kb/)，生产与测试均运行 WeKnora 0.9.0。原生产内网入口 `http://10.242.180.54:18288/kb/`、独立测试入口 `http://10.242.180.54:8289/kb/` 及域名穿透规则保持不变。

## 代码结构

- `src/wanshitong_gateway/`：身份、角色、资料范围、历史、运营与原生 WeKnora API 桥接。
- `src/wanshitong_gateway/compat/`：从旧项目抽出的必要登录、会话、加密和 SQLite 工具，不含旧 RAG 引擎。
- `frontend/`：湾小度用户问答与个人资料界面。
- `vendor/weknora/`：固定版本的上游源码和必要管理端适配，版本及镜像信息见 `upstream.lock.json`。
- `deployment/wanshitong-stable/`：现有部署基线和运行约束，新测试环境须使用独立数据目录、网络和登录配置。
- `deployment/wanshitong-v2/`：新版独立测试栈、离线构建和公共资料复制工具。
- `tests/wanshitong_gateway/`、`tests/identity/`：网关行为与登录合同验证。

## 资料与权限

超级管理员 `taoyifei`（研发系统 userId 为 `325`）负责管理员任免；其他管理员管理资料、系统配置，并只能调整他人的普通、人力角色，不能修改自己或其他管理员，也不能授予管理员身份。超管身份由服务端 `WXD_SUPER_ADMIN_USER_IDS` 配置，页面不可修改；角色保存会记录操作者、目标用户、变更前后角色和时间。

人力角色维护公开人力制度并使用人力内部资料区；人力内部资料仅限人力角色和超级管理员访问，普通管理员同样不能查看、检索、下载或经后台 Trace 读取。普通用户检索公共资料和自己的个人资料。个人上传默认私有，主动共享后才发布到公共范围。角色由湾小度服务端维护，不直接把研发管理系统的角色声明当作知识库权限。

## 使用入口与功能

- 生产问答与资料：[湾小度](https://devmng.nat200.top/kb/)；生产管理后台：[管理入口](https://devmng.nat200.top/kb/admin/)。
- 测试问答与资料：[8289 测试入口](http://10.242.180.54:8289/kb/)；测试管理后台：[8289 管理入口](http://10.242.180.54:8289/kb/admin/)。
- 使用研发管理系统登录；`taoyifei` 为受保护的超级管理员。新同事首次登录后出现在用户列表，可选角色由操作者和目标身份决定；保存后下一次请求即生效，同事刷新页面即可更新入口，无需重新登录或重启。
- 侧栏“我的资料”可上传个人文件；默认仅本人使用，系统管理员可后台管理。主动共享后全员可检索，取消共享保留个人原件。生产与测试顶部统一收为账户菜单，主题与退出在其中。
- 输入框的“资料范围”默认选择公共知识库，包含已公开的人力制度；也可单独选择“公开人力制度”，或与“我的资料”组合。直接点击公开人力制度会把默认公共范围切换为制度范围，选回公共则恢复全部公开资料。人力和超管还可选择人力内部资料；管理员问答也只检索本人的个人库。范围内没有可用资料时提示补充，不自动扩大范围。
- 历史会话位于左侧，可按标题搜索、按日期回看并点击继续对话；桌面侧栏支持收起并记住布局偏好，窄屏使用抽屉。列表和搜索沿用服务端当前返回的最近50个会话，较早数量会单独提示；不在浏览器持久保存历史内容。
- 历史菜单支持本人会话归档、恢复和删除；归档不会删除内容，删除需确认，其他用户不能操作该会话。
- 已有问答后切换资料范围会开启新对话，旧历史保留；侧栏或顶部的“新对话”恢复默认公共范围。历史续问和重新生成沿用原范围，避免旧私有上下文混入仅公共问答。
- 人力角色通过“公开人力制度”和“人力内部资料”维护对应资料；公开制度保持全员可读。
