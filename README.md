# 湾小度 V2

湾小度基于腾讯开源 [WeKnora](https://github.com/Tencent/WeKnora)，提供院内知识问答、研发管理系统单点登录、资料权限管理和个人资料上传。

查看已发布代码请使用 `wanshitong-stable` 分支。功能开发在独立的 `codex/*` 分支进行，先在8289验收，再将同一版本发布到8288；两套环境的用户、资料和历史分别保存。当前生产与测试均运行固定的 WeKnora 0.9.0，上游提交与依赖信息见 [upstream.lock.json](upstream.lock.json)。

## 8289 资料使用改进（测试阶段）

本批只部署到8289，8288仍使用已发布版本。

- 资料列表支持“问这份资料”及选择最多20份资料提问。会话固定文件范围；普通新对话默认公共知识库，服务端每轮核对当前权限。
- “更新版本”先准备新文件，原版继续使用。新版本解析及原件检查通过后再发布；旧版保留在“已归档旧版”，不参与新检索。旧会话明确引用了归档制度时，提示新建对话，历史仍可追溯。个人旧版本仍计入容量和份数。
- “检查资料”核验原件能否下载、大小及哈希、解析状态，记录检查时间；不把这些结果当成所有图片显示或回答准确性的证明。
- 制度说明、操作图示与可填写模板分开标示。真实Excel/Word附件和完整操作指引可在资料列表及展开的引用文档旁下载。含填写示例的附件使用前应替换实际信息；原始包没有的空表不伪造。
- 相同资料在同一资料区重复上传会返回现有文件，不重复解析或占用个人额度；同名不同内容提示使用版本更新。
- 没有资料支撑的模型回答显示来源说明。确知零检索结果时写“未找到相关资料”；只有无引用证据时写“未引用知识库资料”，历史与实时回答一致。

问指定文件使用WeKnora原生文件检索接口。文件白名单不能与整库目标同时传入，避免上游将范围扩展到整库；用户主动指定文件时沿用原生文件模式；系统为权限与版本生成的普通资料库白名单继续使用原配置的向量和关键词阈值，并保留已配置的重排与生成设置。本批未修改WeKnora检索算法。 原生API补充了受限Key的文件归属核验，避免原接口一律拒绝指定文件；未扩大Key授权范围，后台恢复和续问仍重新校验。原生重建保留官方Go编译必需的嵌入文档，官网工程、截图和本地业务文档不随代码提交。

## 代码结构

- `src/wanshitong_gateway/`：身份、角色、资料范围、历史、运营与原生 WeKnora API 桥接。
- `src/wanshitong_gateway/compat/`：从旧项目抽出的必要登录、会话、加密和 SQLite 工具，不含旧 RAG 引擎。
- `frontend/`：湾小度用户问答与个人资料界面。
- `vendor/weknora/`：固定版本的上游源码和必要管理端适配，版本及镜像信息见 `upstream.lock.json`。
- `deployment/wanshitong-stable/`：历史部署工具和运行约束；当前运行项目与目录见下方“运行维护”。
- `deployment/wanshitong-v2/`：新版独立测试栈、离线构建和公共资料复制工具。
- `tests/wanshitong_gateway/`、`tests/identity/`：网关行为与登录合同验证。

## 资料与权限

超级管理员负责管理员任免；其他管理员管理资料、系统配置，并只能调整他人的普通、人力角色，不能修改自己或其他管理员，也不能授予管理员身份。超级管理员由部署人员在服务端 `WXD_SUPER_ADMIN_USER_IDS` 配置，不在文档中指定个人账号或用户ID，页面不可授予或撤销。角色保存会记录操作者、目标用户、变更前后角色和时间。

以下资料权限已于2026-11-04在8289验收，并经授权同步发布到8288：

| 资料区 | 查看、检索与下载 | 新增、修改与删除 |
| --- | --- | --- |
| 公共资料 | 所有人 | 管理员、超级管理员 |
| 公开人力制度 | 所有人 | 管理员、人力角色、超级管理员 |
| 人力内部资料 | 人力角色、超级管理员 | 人力角色、超级管理员 |
| 个人资料 | 仅本人 | 仅本人 |

管理员和超级管理员也不能经后台、Trace、引用、图片或下载访问他人的个人资料。个人资料共享功能暂时关闭：所有角色均不展示共享入口或状态，接口也拒绝共享及撤回请求，保留实现供以后明确授权后开放。已发布的公共副本仍由管理员按公共资料权限独立维护，删除个人原件不会连带撤回公共副本。角色由湾小度服务端维护，不直接把研发管理系统的角色声明当作知识库权限。

新同事首次登录后出现在用户列表，已有历史用户再次登录时可补全账号和部门。权限保存后在后续请求中生效；已经打开的页面刷新后更新角色入口，无需重新登录或重启服务。

个人资料默认每人250MB、50份，单文件最多50MB；容量按原件计算，已接受的待解析文件和解析失败原件同样占用额度。达到容量或份数的80%时提醒，满额暂停新增；已有问答、下载和本人删除继续可用。个人任务每人同时处理1份，最多等待5份，排队及投递状态保存在网关数据库，原件暂存在同一持久卷的 `personal-uploads/`。删除完成后释放额度，重试与新增共用本人的解析槽，服务重启按记录恢复，不重复盲投递。公共资料、公开人力制度和人力内部资料不套用个人容量、份数或排队限制，原生解析及模型并发配置保持原样。

超级管理员可在“用户与角色”中单独调整个人额度，配置项不提供他人文件内容、文件名或用量；额度保存不改变角色和文件访问权限。个人写入统一通过“我的资料”，原生管理后台的个人写入会提示返回该入口，保证额度和解析队列不会被绕过。额度功能已在8289验收，并于2026-11-04经授权发布到8288。

## 日常使用

- 侧栏“我的资料”支持上传个人文件，仅本人使用，当前不展示“共享给全员”功能。主题切换与退出位于右上角账户菜单。
- 输入框的“资料范围”默认选择公共知识库，包含已公开的人力制度；可单独选择“公开人力制度”，或与“我的资料”组合。选中公共知识库即覆盖其中的制度范围。人力和超级管理员还可选择人力内部资料；问答中的个人资料始终按当前登录者隔离。范围内没有可用资料时提示补充，不自动扩大检索范围。
- 历史会话位于左侧，支持服务端标题搜索和“加载更多”，搜索不局限于当前已加载的列表。桌面侧栏可收起，窄屏使用抽屉；点击会话可继续对话。
- 会话的“…”菜单支持重命名、归档、恢复和删除。名称保存后立即同步当前页面的侧栏、顶栏及搜索结果，无需手动刷新；重新打开页面、继续提问、归档或恢复后仍保留。改名不修改原问答内容或会话排序，其他用户不能操作该会话。
- 归档保留问答内容，删除需确认。已有问答后切换资料范围会开启新对话；“新对话”恢复默认公共范围，历史续问和重新生成沿用原范围。
- 回答支持“复制回答”和“复制含来源”。展开“引用依据”后，可在附件名称旁直接“下载原件”，同文件多段只显示一个下载入口；片段阅读、图片预览和放大沿用当前资料权限。
- 人力角色通过“公开人力制度”和“人力内部资料”维护对应资料，公开制度全员可读。资料数量及处理状态以当前管理后台为准。

## 本地验证

Python 版本为 3.11；使用隔离环境安装 `requirements.lock`，然后执行：

```sh
python -m pytest tests/wanshitong_gateway tests/identity
python -m ruff check src/wanshitong_gateway
```

前端使用其自身 `package.json` 中的检查和构建命令。真实模型、文档解析与 8289 登录需要在独立测试栈验证；离线测试不能代替实际问答验收。
