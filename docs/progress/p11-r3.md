# P11-R3 前端连接操作与企业风格收敛

## 基线与边界

2026-09-05 从已合入 R1/R2 的 `codex/p11-release` 开始。
先执行 `git fetch origin --prune`，退出 0；工作区干净，P11 本地与远端
左右计数为 `0 0`，基线为 `1754c97ed706e69cecfdf3ed8dcad08767620795`。
确认本地、远端没有 R3 分支后，创建 `codex/p11-r3-console-polish`。

本阶段保留 React/TypeScript/Vite、Session、OpenAPI 类型与 Lucide。
不改 RAG 算法，不改数据库迁移或已应用校验和，不打开私人 DOC/DOCX，
不读取或解密真实密钥。测试只使用合成口令、合成 Workspace、合成 DOCX、
临时 SQLite 与现有 MockTransport。没有真实 Jina/百炼请求。

配置 Jina/备用连接 → 创建空 KB 并绑定方案 → 上传合成 DOCX → 编辑当前方案 →
建立候选索引 → 构建中查询断言仍为旧 active 且有证据 → Job 完成 → 查询断言
新 active 与旧版本不同且有证据 → 打开引用。浏览器外部 URL 请求列表为空，axe
检查无违规。axe 结果只代表执行过的场景，不等同于全部可访问性问题均已消除。
